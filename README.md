# MedStock

## SIH1627 — Medicine Inventory & Supply Chain

MedStock is a web-based medicine inventory and supply chain management system designed to help government hospitals manage medicine stock, expiry dates, requirements, and transfers.

## Main Features

- 🏥 Hospital management
- 💊 Medicine inventory
- 📦 Stock tracking
- 📅 Expiry date tracking
- 🔴 Low-stock alerts
- ⚠️ Near-expiry alerts
- 📋 Hospital medicine requirements
- 🔄 Medicine transfer suggestions
- 📊 Dashboard

## Technology

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Git
- GitHub

## Project Goal

To help ensure that the right medicine reaches the right hospital at the right time while reducing medicine shortages and wastage.
